测速设置

间隔填 0 表示不自动测速，只在点「立即测速」时执行。候选数越大，失败时可切换的备选越多。

域名解析（DDNS） 把最优 IP 写到你的域名

密钥保存在数据目录的 ddns.env 里，留空表示不修改已保存的值。
这两个按钮用的是已经保存的设置——刚改完的密钥请先点上方的「保存全部设置」，否则测的还是旧的。
「测试密钥」只读：只确认密钥能不能用、能不能查到这个域名、现在指向哪里，不会改动你的解析。
「立即更新一次」才会真的把当前最优 IP 写进去，不用等下一个测速周期。

备份与恢复 把全部设置存成一个文件

导出文件里带着 AdGuard 密码和各家的 DNS 密钥——请当密码一样保管，不要发到群里。
「从文件恢复」会用文件里的内容覆盖当前全部设置（后台登录密码不受影响，也不会被改）。
什么时候用得上：重装应用、换一台 NAS、或者哪天数据目录又被清空了。
下面这段就是备份文件的内容。如果刚才浏览器没弹出下载（飞牛桌面把后台嵌在 iframe 里时个别浏览器会拦下载）， 点一下框里全选复制，粘贴到记事本里存成 .json 文件即可。

登录密码 这个后台唯一的门

至少 8 位；别用 12345678、aaaaaaaa 这类连续或重复的，也别用 password、admin123 这类最常见的。改完立即生效，不用重启，也不用再去「应用设置」里改。
