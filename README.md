# Cloudflare 优选 IP + AdGuard Home + DDNS（飞牛 fnOS）

在飞牛 NAS 上一键搞定三件事：测出你家网络真能连上的最快 Cloudflare 节点、
写进 AdGuard Home 的 DNS 重写、更新你自有域名的解析记录。
一个容器、一个后台界面，装完点几下鼠标就能用。

## 它能做什么

| 做什么 | 怎么起作用 |
|---|---|
| 优选 IP | 从 Cloudflare 官方地址段采样，先筛延迟，再用真实 HTTPS 请求确认这个 IP 真能打开网站，最后测实际带宽排序 |
| 写 AdGuard | 把最优 IP 写进 DNS 重写表，局域网设备自动走这条线 |
| DDNS | 把最优 IP 写进自有域名的 A 记录，支持 Cloudflare / 阿里云 / 腾讯云 DNSPod / 华为云 |
| 出问题看得见 | 实时运行日志；「测试密钥」只读校验不动你的解析；「立即更新一次」不用等下一个周期 |

## 安装

1. 到 [Releases](../../releases) 下载 `cf-ddns-sidecar-<版本>.fpk`；
2. 飞牛桌面 → **应用中心** → 右上角 **设置** → **手动安装应用** → 选这个文件；
3. 装完桌面出现「优选 IP · DDNS」图标，点开就是后台（也可以浏览器访问 `http://飞牛IP:端口`）。

安装向导只问两件事：**后台端口**（留空 = 8080）和**登录密码**（留空自动生成，能在运行日志里看到）。
装完想改这两项，走「应用中心 → 本应用 → 设置」，保存即生效，不用重启。

## 第一次使用

1. **AdGuard Home**：填地址（如 `http://192.168.1.2:3000`）、用户名、密码；
2. **要加速的域名**：加一个套了 Cloudflare 的域名，比如 `openai.com`；
3. **测速设置**：定个自动测速间隔（默认 60 分钟，填 0 = 只在手动点时测）；
4. **域名解析（DDNS）**：要同步到自己域名就填这一块——服务商、域名、密钥、同步几条 IP；
5. 点「保存全部设置」，再点「立即测速」。

密钥留空表示「不修改已保存的值」，改域名时不用重填一遍。

## 几个容易踩的坑

- **测速必须直连**。测的是「你家宽带 → Cloudflare 边缘」这段路，走代理测出来的是代理的线路，对你没用。程序会自己清掉代理环境变量，但如果你在**路由器**上做了全局透明代理，得单独给 NAS 放行直连。
- **「同步几条 IP」是对齐，不是追加**。填 3 条，这个域名下就只留 3 条，原来那些同名 A 记录（包括你手工加的）会被删掉；测不出 IP 的时候一条都不删。
- **多条 A 记录时访问者是随机挑一条**，不是「都走最快的」。所以 2～3 条是「一条挂了还有备胎」，填到 5 条以上，大部分访问反而落到慢的那些上。
- **AdGuard 里它只动自己认领的那几个域名**（也就是「要加速的域名」这一批）。其他记录标着「不归这个程序管」，一条都不碰。拿不准就先点「看看现在写了哪几条」看一眼。
- **忘了后台密码**：应用中心 → 本应用 → 设置里重设；也可以在后台最下面的「登录密码」卡片里改。

## 备份与恢复

后台最下面的「备份与恢复」能导出/导入一份 `.json`（里面连密钥一起带上了，请当密码一样保管）。
重装、换 NAS、数据目录被清空，都靠它恢复。

程序每次保存也会自己留一份备份；万一只剩下备份，启动时会自己搬回来，并在界面上挂一条红条提醒你核对。

数据目录在存储空间根目录下的 `cf-ddns-sidecar-data` 文件夹里。

## 常见问题

| 现象 | 处理 |
|---|---|
| 后台打不开 | 确认端口对不对（默认 8080）；端口被 NAS 上别的服务占了就换一个 |
| 写进 AdGuard 了但设备还走老 IP | 设备或 AdGuard 的 DNS 缓存，重连一次网络，或在 AdGuard 里清一下缓存 |
| 域名解析报 403 / 401 | 密钥权限不够。Cloudflare 令牌要有「编辑区域 DNS」权限，Zone ID 要填对 |
| 测速报「没有产出可用 IP」 | 极少见（已内置官方地址段保底），多半是 NAS 完全没有外网出口 |
| 「上次结果：失败」 | 看运行日志最后几行。失败会自动重试一次，所以这里的失败是重试之后仍然失败 |
| 改了 TTL，外面查到的还是旧 IP | TTL 是让全世界缓存多久，改小了也得等旧的那一轮过期 |
| 点「导出配置文件」浏览器没反应 | 页面下方会出现一段文本框，全选复制、存成 `.json` 就行 |
| 想卸载干净 | 卸载不会删数据。要清干净就去「文件管理」删掉 `cf-ddns-sidecar-data` 和 `cf-ddns-sidecar-backup` 两个文件夹 |
| 想在外面也能打开后台 | 用 Tailscale / ZeroTier 这类组网工具，别在路由器上开端口映射 |
